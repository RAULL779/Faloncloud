Sobre o projeto

FALON CLOUD é uma interface independente em desenvolvimento. Versão 1.0 — catálogo, busca, filtros, favoritos e perfil local.

Transparência — streaming ainda não conectado. Esta versão entrega a interface funcional do catálogo. Para iniciar Fortnite ou outros jogos pela nuvem, ainda será necessário contratar/configurar servidores com GPU, implementar streaming de baixa latência e integrar os serviços e licenças apropriados. O botão JOGAR abre a ficha do jogo, não inicia uma sessão real.
