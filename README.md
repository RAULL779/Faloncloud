FALON CLOUD — VERSÃO 1.0

Como usar:
1. Extraia o arquivo ZIP.
2. Abra index.html no Chrome ou outro navegador.

Inclui:
- Interface responsiva para celular.
- Página inicial e biblioteca.
- Busca e filtros por categoria.
- Favoritos salvos no navegador.
- Perfil local com apelido.
- Ficha informativa de cada jogo.

Importante:
Esta é a versão final da INTERFACE 1.0, não um serviço de cloud gaming operacional.
O streaming real exige servidores com GPU, sistema de transmissão de baixa latência,
infraestrutura de rede e integração/licenças adequadas. O botão JOGAR ainda não inicia
uma sessão de jogo.
